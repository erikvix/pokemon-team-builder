# Pokémon Team Builder

Aplicação para montar e analisar times de Pokémon.

## Sobre

O objetivo do projeto é permitir que o usuário monte times de até 6 Pokémon,
visualize os status de cada um e entenda as forças e fraquezas do time como um
todo (resistências e vulnerabilidades por tipo).

## Status

Projeto em fase inicial — a stack e a estrutura ainda serão definidas.

## Como rodar

Ainda não há código para executar. As instruções serão adicionadas assim que o
projeto for inicializado.
